# 🚀 Toon Tanks 🎮

Welcome to **Toon Tanks**!  
What started as a "simple" Udemy tutorial quickly turned into an epic journey of tank battles, AI trickery, and endless debugging.  
Built using **Unreal Engine 5**, this project became my playground for mastering gameplay mechanics, Blueprints, and C++ programming.

---

## 🎮 Game Features

- **Tank Combat System**  
  Players control a tank with smooth movement and satisfying firing mechanics. Blowing stuff up has never been so fun.

- **Enemy AI**  
  AI-driven enemies that actively fight back—adding tension and challenge to every battle.

- **Health and Damage System**  
  Both player and enemy tanks have health points, encouraging both offense and defense in gameplay.

- **Shooting Mechanics**  
  Responsive and accurate tank cannon firing system to make you feel like a true battlefield commander.

- **3D Environment Design**  
  A vibrant and dynamic cartoon-style battlefield to enhance visual engagement.

---

## 🧠 What I Learned

- **Core Gameplay Mechanics**  
  Developed using Blueprints and C++, combining visual scripting with hands-on programming.

- **Player & Enemy Behavior Design**  
  Designed interactive enemy AI and player systems that make each match dynamic and engaging.

- **Project Structuring in Unreal Engine**  
  Learned how to organize assets, logic, and systems efficiently for scalability and maintainability.

- **Debugging & Troubleshooting**  
  Faced and resolved bugs, performance issues, and logic errors—an essential part of the learning curve.

---

## 🚀 What's Next?

Toon Tanks has been a tremendous stepping stone in my game development journey.  
I'm excited to bring these skills into more ambitious projects—think **bigger tanks, smarter AI, and even crazier battles**!
